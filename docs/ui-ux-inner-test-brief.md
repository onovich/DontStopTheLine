# 内测 UI/UX 设计 Brief：工业信号台

## 体验目标

首位无背景玩家应在 10 秒内知道“连接设备，让货物持续出售”，60 秒内完成第一条盈利产线，3 分钟内理解并解决一次阻塞。画布是游戏，不是被面板包围的编辑器。

## 视觉立场

- 题材语汇：石墨控制桌、搪瓷设备铭牌、蚀刻网格、机械端口、琥珀指示灯、青色物流信号、朱红故障标识。
- 字体角色：窄体工业展示字用于设备与章节；中性无衬线用于教程；等宽表格数字用于钱、吞吐和容量。
- 记忆点：每件货物从实体输出端口离开，沿有方向的线路运动，在拥堵时形成可追踪的压力链。
- 克制：无紫色渐变、毛玻璃卡片、通用 SaaS 仪表盘、过量圆角、等权按钮墙和无意义大留白。

## 主界面线框

```text
┌ 资金 / 吞吐 / 当前任务 ───────────────────── 暂停 1x 2x 4x ┐
├─────────────┬────────────────────────────────┬──────────────┤
│ 建造        │                                │ 设备检查器   │
│ 生产        │        有边界的工厂画布        │ 名称/配方    │
│ 加工        │   端口 · 货物 · 压力 · 状态    │ 阻塞/建议    │
│ 物流/销售   │                                │ 升级/出售    │
├─────────────┴────────────────────────────────┴──────────────┤
│ 当前工具 / 撤销       一句情境提示          调试层（可选）  │
└────────────────────────────────────────────────────────────┘
```

## 信息与状态

- 默认节点只显示玩家名称、图标、工作进度、端口和当前状态；内部 ID、原始槽位和枚举仅在调试层显示。
- 状态必须同时使用形状、图标、文字和颜色：待料蓝、工作琥珀、畅通青、拥堵橙、阻塞朱红、高级紫铜。
- 阻塞首先在画布显现；选择设备后检查器显示一句原因、受影响链路和一个可执行建议。

## 首局披露

初始只开放原质源、基础加工器、售卖器与端口连线。仓储、宽线路、路由和迷宫节点在玩家遇到相应问题后出现。教程锚定目标节点和端口，不长期占据整行。
