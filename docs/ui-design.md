# UI / UX 设计方向

## 视觉命题

核心不是“工业写实工厂”，而是“会呼吸的系统图”。采用深色中性画布、低饱和节点外壳和高亮物流色：输入蓝、生产琥珀、正常输出青绿、阻塞橙红、错误洋红。颜色之外同时使用图标、线型与动画节奏，保证色弱可读。

## 主界面布局

- 顶栏：现金、净收入/分钟、当前等级、目标进度、暂停与 1x/2x/4x。
- 左侧构建抽屉：按生产、加工、物流、储存、销售分类；卡片展示占地、价格、端口和锁定条件。
- 中央无限感有限画布：边界明确，网格只在放置/重构时增强；节点本体展示最少但关键的输入、工作、输出状态。
- 右侧检查器：选中对象的配方、缓冲、吞吐、阻塞原因、升级/出售；默认收起以保留画布。
- 底部情境栏：连接、拆除、复制、撤销；教程和警告在此出现，避免模态框打断观察。

## 交互规则

点击选中，拖拽移动；从输出端拖至输入端创建连接，悬停目标时预演兼容性、长度费用与预计运输时间。放置前显示幽灵占地和余额变化。重构模式暂停扣费，提交时展示净成本；危险拆除二次确认并明确会损失的库存。

阻塞必须“在画布上一眼可见、在检查器中一句话说清、再给一个行动建议”。例如线路满载时线条变粗并脉冲，节点输出端出现堆积环；检查器显示 `LINE_FULL：连接线在途容量已满` 以及升级/并联建议。

## 信息层级与镜头

- 远景：只显示节点类别、运行/阻塞状态、聚合流量。
- 中景：显示端口、缓冲占用、主要运输点。
- 近景：显示配方材料、逐槽进度及高级小游戏内部画面。
- 瓶颈视图覆盖吞吐热力与等待时间，正常游玩时不常驻，避免视觉噪声。

## 首 30 分钟

初始画布已有不可出售的源点生产者与售卖器。教程只要求连接两点并观察第一次售卖；随后依次引入输出阻塞、加工配方、储存缓冲、销售带宽。一次只教学一种失败原因，所有提示允许跳过并可在图鉴重播。

## 响应式与无障碍

最低桌面 1280x720，布局在窄屏切为底部构建抽屉与全屏检查器；平板使用 44px 以上触控目标和双指镜头。所有操作有键盘路径，支持减少动态效果、UI 缩放、对比度模式、暂停时阅读，并为图标提供文本标签。
