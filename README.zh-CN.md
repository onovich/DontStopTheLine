# DontStopTheLine

[English](README.md)

《产线别停》，在有限画布里搭建节点式自动化产线的 Web 优先游戏。

![DontStopTheLine 封面](docs/cover.png)

## 项目包含什么

- Web 优先。
- 节点式物流。
- 可玩的生产循环。

## 快速开始

安装依赖并启动本地版本：

```bash
pnpm install
```

仓库还提供 `pnpm run build`、`pnpm run test`、`pnpm run lint`。

## 仓库结构

- `apps/` — 可运行应用。
- `packages/` — 共享包与领域模块。
- `docs/` — 项目文档与设计说明。
- `.github` — 自动化与 GitHub Pages 工作流。
- `package.json` — 包脚本与依赖。
