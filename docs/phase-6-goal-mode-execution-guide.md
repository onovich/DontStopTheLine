# Phase 6 性能与发布候选 Goal 模式执行指南

状态：READY；预算 12 轮（1-9 主体、10-11 缓冲、12 验收）。

## Goal Prompt

将产线别停提升为发布候选：建立 1,000 节点/线路可重复压力基准，完成 Canvas LOD 与运输点对象池、崩溃恢复、无障碍核查、桌面打包 dry-run 和发布清单。不得改变权威模拟语义或借由删减功能伪造性能。

## 范围

1 基准场景与指标；2-3 运输点池化/批渲染；4 LOD/离屏表现降级；5 simulation 批处理/性能计数；6 崩溃恢复和存档恢复演练；7 键盘、焦点、对比度、减少动态效果审计；8 Windows Electron 打包 dry-run；9 发布清单、版本与已知风险；10-11 修复；12 干净验收。

## 验收

固定 seed 的 1,000 节点场景可完成模拟并产出基准报告；主线程表现与模拟预算可观测；无障碍关键路径有 Playwright/手工清单证据；存档恢复和桌面启动 smoke 通过。每轮 Debug/架构自检、验证、commit/push；最终冻结安装、check、build、smoke、diff check 全绿。

## 非范围

不扩展第二章、动态市场、多人、云端、第二小游戏或正式美术重制。
